Design an EcoRoute Marketplace that allows users to redeem their Green Points for eco-friendly products and services. Incorporate social and interactive features similar to Facebook Marketplace, such as seller profiles, in-app messaging, price negotiation, and location-based suggestions.

1. Create the Marketplace Tab in the Navigation Bar

Goal: Add a Marketplace tab in the bottom navigation bar for easy access.

New Tab: Add a "Marketplace" tab in the bottom navigation bar (between Rewards and Profile).
Use a clear icon (e.g., shopping cart or gift box).
Label the tab with "Marketplace".
Styling:
Primary Green (#2D8653), Font: Inter, line height 1.6.
Use rounded borders: 6px for inputs, 10px for cards, 14px for panels.
2. Marketplace Landing Page Layout

Goal: The landing page should display all available products that users can redeem with their Green Points.

Header:
Title: "Marketplace".
Search Bar: Allow users to search for products or services.
Category Filters: Include categories like:
Bike Accessories
Eco Products
Coffee Discounts
Gym Passes
Public Transport Benefits
Bookstore Discounts
Student Offers
Product Grid Layout:
Use a grid layout to display products.
Each product card should include:
Product Image.
Product Name.
Short Description.
Points Required (e.g., 200 Green Points).
A "View Details" button that leads to the Product Detail Page.
Social proof (e.g., ratings or seller information).
Product Interaction:
Add hover effects or small animations for user engagement (e.g., expanding cards, highlighting the “View” button).
Add a "Popular" label on trending items.
Social and Interactive Features:
User Reviews: Add a star rating or text reviews below the product.
Chat Icon: Allow users to message sellers directly for any questions.
Offer/Negotiate: Allow users to make offers on products, similar to Facebook Marketplace’s "Make Offer" feature.
3. Product Detail Page

Goal: Provide users with a detailed view of a product and enable Green Points redemption.

Header:
Product Title.
Back Button to navigate back to the Marketplace landing page.
Product Details:
Large Product Image.
Full Description of the product or service.
Green Points Required (e.g., 200 Green Points).
"Redeem with Points" Button in EcoRoute Green (#2D8653).
Seller Profile:
Show seller name or store name with a profile picture.
Seller Rating: Add a star rating or user feedback for trust.
Social Features:
In-App Messaging: Add a "Message Seller" button that opens a direct chat with the seller.
Share Button: Allow users to share the product via social media (Facebook, Instagram).
4. Checkout Page

Goal: Allow users to confirm their Green Points redemption and review selected products.

Header:
Title: "Checkout".
Product Summary:
List all redeemed products.
For each product:
Image, Name, and Green Points Spent.
Total Points Summary:
Show the total Green Points spent.
Confirm Redemption:
Add a "Confirm Redemption" button to finalize the transaction.
Add a "Cancel" button to return to the Marketplace.
Social Features:
After redemption, allow users to share the redeemed items on their profile or social media.
5. Rewards Confirmation Page

Goal: Show users a success message once they have redeemed their Green Points for a product.

Success Message:
Display a message like "Congratulations! Your points have been redeemed."
List the redeemed products and the total Green Points spent.
What’s Next Section:
Suggest other products the user can redeem with their remaining points.
Allow the user to either continue shopping or return to the home page.
Social Features:
Add an option to post achievements or redeemed rewards on the user's profile.
Include a "Back to Marketplace" button.
6. Social and Interactive Features to Add

Here are additional interactive features to further enrich the user experience:

User Profiles:
Add a user profile where users can track their redeemed rewards, points balance, and review history.
Notifications:
Notify users when their preferred products are back in stock or when prices drop.
Price Negotiation:
Allow users to make offers on products, either directly within the app or by sending a message to the seller.
Location-based Filtering:
Let users filter products based on location to find nearby offers or sellers.
Add an "Available Near You" filter option.
Eco-Partner Badge:
Add a badge for verified Eco-Partners or eco-friendly sellers.
Geo-Location Based Suggestions:
Display local deals or local sellers based on the user's current location.
Community Buy:
Allow users to form a group buy for discounted prices on eco-friendly products.
Design Specifications:
Spacing & Layout:
Use 16px spacing for padding and margins.
Ensure that product cards and buttons are touch-friendly with at least 44px clickable areas.
Colors:
Primary Green: #2D8653 for buttons, highlights, and active states.
Dark Green: #1A5C38 for backgrounds and card sections.
Gray tones: For text and non-interactive elements.
Typography:
Use Inter font family, with line height 1.6 for readability.
Bold text for product names and Green Points cost.
Icons & Imagery:
Use Eco-friendly icons such as bikes, leaves, or trees for product categories.
Ensure high-quality images for each product.
